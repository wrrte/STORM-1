# Frostbite Random neighbors: seed 11010 상세 결과

저장된 critic 예측만 분석했습니다. 모델 추론이나 추가 학습은 실행하지 않았습니다. 원래 평가 파일을 보존하고 상세 결과를 이 디렉터리에 별도로 저장했습니다.

## 체크포인트와 평가 문맥

- Run: `Frostbite-score-screen-frostbite_neighbor_screen_20261107-seed11010_randomneighor`
- Variant: Random neighbors; salience는 value_diff × TD-error의 multiply 규칙을 유지하고 이웃만 무작위로 선택합니다.
- 학습 seed: 11010; world model/critic 체크포인트: 100,000 agent steps.
- 최종 정책 평가: BF16, 20 episodes 평균 2177.0점. FP32 기록은 2207.5점입니다. 이 정책 평가 에피소드와 아래 critic 진단 에피소드는 서로 다른 데이터입니다.
- 문맥 수집 정책: Baseline seed 3710의 100k 체크포인트. Random 정책으로 새로 수집한 문맥이 아닙니다.
- 수집/평가 난수 seed: 2027; action repeat 4; 입력 64 × 64 RGB. 20,000개는 agent-step 관측 수이며 raw emulator frame 수가 아닙니다.
- 관측 에피소드: 20개(19개 완료, 마지막 1개 부분 관측).
- 블록: 같은 원래 RAM igloo stage가 유지되는 연속 관측, 최대 64개, 에피소드 경계 통과 금지.
- 원래 igloo stage 라벨은 RAM[77]=255이면 0, 그 외에는 RAM[77]+1입니다.
- 이글루는 모든 블록 관측의 `[10:17, 42:58, :]` 영역을 7 × 16 RGB 템플릿 17개(0–16단계)로 교체합니다. 나머지 픽셀과 행동 이력은 단계 간 동일하며 배경 노이즈는 없습니다.
- 블록마다 앞 8개 관측으로 문맥을 초기화하고 이후 시점의 critic 값을 계산합니다. 블록·단계별 난수 초기화는 평가 프로토콜에 기록된 방식을 따릅니다.
- 각 문맥·단계는 latent draw 1회이며 반복 latent 평균이 아닙니다.

## 정렬 점수 정의와 평균·95% CI

문맥 i마다 stage 인덱스 (0,…,16)과 critic 값 (v_i(0),…,v_i(16)) 사이의 Spearman ρ와 Kendall τ_b를 구합니다. 그 뒤 문맥별 상관계수를 같은 가중치로 평균합니다. ties는 SciPy의 기본 순위 처리를 사용합니다. 17단계 예측이 상수이면 상관계수는 정의되지 않으므로 0으로 바꾸지 않고 제외합니다.

20개 에피소드 ID를 복원 추출하는 bootstrap 10,000회(seed 2027)를 사용합니다. 선택된 각 에피소드의 모든 문맥과 반복 선택 횟수를 유지하고, 매 회 선택된 문맥 수를 분모로 다시 계산합니다. 2.5/97.5 percentile이 95% CI입니다. 아래 모든 bootstrap 결과의 에피소드 선택을 `bootstrap_replicates.npz`에 저장했습니다.

| 지표 | 평균 [95% CI] | 유효 문맥 | 정의 불가 |
| --- | --- | --- | --- |
| spearman | 0.1076 [0.0838, 0.1315] | 17421 | 0 |
