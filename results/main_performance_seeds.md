# 논문 main performance의 STORM 시드 대조표

기준: `iclr2027_conference.tex`, `tab:main_performance`의 STORM / STORM+ours 열.
각 행의 시드는 두 방법에 공통으로 사용되었다. DRAMA 시드는 이 STORM workbook의 분석 범위에 포함하지 않는다.

2026-09-26의 STORM-1 커밋 `60612ee` workbook과 집계 규칙으로 게임 26개 및 집계 지표 5개가 모두 재현된다.
아래 점수는 모두 현재 `converted_results.xlsx`의 숨김 시트 `Ablation Results`에서도 확인했다.

원본 Config 행은 STORM의 `Retrieval 미사용`, STORM+ours의 `target: 16 (anchor 미설정)`이다. 집계 함수는 `results/update_tex.py:load_results`이며, `EXCLUDED_SEEDS`에 지정된 시드는 제외한다.

현재 workbook을 현재 loader의 첫 점수 선택 규칙으로 그대로 읽으면 24게임이 일치하고 다음 2게임이 달라진다.

- Kangaroo: 논문에 사용된 4시드에 이후 추가된 2020을 넣으면 STORM / STORM+ours가 2280 / 2335로 바뀐다. 논문의 2071.2 / 2258.8은 위 4시드로 정확히 재현된다.
- Krull: 논문은 STORM seed 2020에서 6404.5, seed 9999에서 6289.0을 사용했다. 현재 같은 셀에서 각각 세 번째와 두 번째에 남아 있는 점수이다. 첫 점수 5987.0과 6771.0을 사용하면 STORM 평균은 6553.9가 되어 논문 6541과 달라진다. STORM+ours는 6800.9로 일치한다.

21게임은 4시드, Gopher / KungFuMaster / UpNDown은 3시드, Krull / PrivateEye는 5시드이다. 총 103 공통 (게임, 시드)쌍으로, 논문의 모든 게임 4시드라는 설명과 차이가 있다.

`main_performance_seeds.xlsx`에는 206개 방법별 시드 점수, 현재 원본 셀 주소와 중복 점수 선택 순서, 현재 loader와의 비교 및 원본 SHA256을 함께 기록했다.
